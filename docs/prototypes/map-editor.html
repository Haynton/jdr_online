Fumble QuestÉditeur de carte
Sols : glisse pour peindre. Murs et portes : vise le bord entre deux cases.
Objets : R choisit le sens, clic sur un objet posé pour le tourner.
Passage : choisis ce qui bloque les pions, objet par objet ou case par case.
Retirer : clic droit ou Suppr sur un objet ou un mur. Ctrl Z pour annuler.
Image : glisse ou choisis une image, puis indique sa largeur en cases pour caler la grille.
Passage : peins les cases que les pions ne peuvent pas traverser.
Ctrl Z pour annuler un réglage.
